# Better Off Local – Implementation Brief 10
# Store and Release Readiness

## Objective
Prepare the Better Off Local mobile app for distribution.

Focus on:
- app store readiness
- release configuration
- branding assets
- privacy/legal links
- build and release preparation

---

## Mobile App Release Configuration

Ensure production build settings exist for:

### iOS
- release build configuration
- bundle identifier
- signing configuration
- App Store Connect integration
- TestFlight distribution enabled

### Android
- release build configuration
- application ID
- signing configuration
- Play Console preparation
- internal testing track support

---

## App Assets

Prepare placeholders if necessary for:

### App Icon
Multiple sizes required.

### Splash Screen
Branded splash screen.

### App Name
Better Off Local

---

## Store Metadata

Prepare store listing information.

### App Description
Explain:

- discover local deals
- support local businesses
- redeem offers easily

### Keywords
Examples:

local deals  
discount app  
local offers  
support local  
restaurant deals  

---

## Legal Pages

Ensure app includes links to:

- Privacy Policy
- Terms of Service

These should be accessible from the settings screen.

---

## App Permissions

Ensure permissions messaging is clear for:

### Location
Used to show nearby offers.

### Camera
Used for redemption scanning.

### Notifications
Used to alert users about nearby offers and account activity.

---

## Analytics / Crash Reporting

Prepare integration for:

- crash reporting
- basic app analytics

Do not build complex dashboards yet.

---

## Test Distribution

Ensure ability to distribute test builds via:

### iOS
TestFlight.

### Android
Internal testing track.

---

## Basic Release Checklist

Verify before launch:

- user sign-up works
- membership purchase works
- offer discovery works
- redemption works
- retailer portal works
- admin approvals work
- notifications appear correctly

---

## Constraints

- do not redesign UI
- focus on release readiness
- ensure compliance with store requirements
- keep configuration simple and clear

---

## Acceptance Criteria

- mobile app builds in release mode
- test builds can be distributed
- store assets exist
- legal links accessible
- permission explanations present
