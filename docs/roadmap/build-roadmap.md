# Build Roadmap

## Phase 1 — Foundation (Weeks 1–2)

- [ ] Monorepo scaffolding (Turborepo + pnpm workspaces)
- [ ] Supabase project setup (local + hosted)
- [ ] Core database schema + migrations
- [ ] Auth flows (consumer sign up/in, retailer sign up/in)
- [ ] Shared `packages/types` and `packages/config`

## Phase 2 — Retailer Portal MVP (Weeks 3–4)

- [ ] Retailer onboarding flow
- [ ] Retailer profile management
- [ ] QR code generation per retailer
- [ ] Basic dashboard (visit counts)
- [ ] Shared `packages/ui` component library started

## Phase 3 — Mobile App MVP (Weeks 5–7)

- [ ] Consumer onboarding + auth
- [ ] Retailer discovery (map + list view)
- [ ] QR code scanner
- [ ] Points earning flow
- [ ] Points balance display
- [ ] Basic rewards catalogue

## Phase 4 — Admin Portal MVP (Weeks 8–9)

- [ ] Retailer approval workflow
- [ ] User management
- [ ] Platform analytics overview
- [ ] Reward configuration

## Phase 5 — Polish & Beta (Weeks 10–12)

- [ ] Push notifications (visit reminders, reward unlocks)
- [ ] Retailer-specific offers
- [ ] Improved discovery (search, filters, categories)
- [ ] Redemption flow end-to-end
- [ ] Performance tuning and error handling
- [ ] Beta TestFlight / Play Store release

## Phase 6 — Launch Prep

- [ ] Production Supabase setup (RLS audit, backups)
- [ ] CI/CD pipelines (GitHub Actions)
- [ ] App Store / Play Store submission
- [ ] Monitoring and alerting
